# Customizable Tracker

A simple and flexible tracker for managing activities, goals, and progress.

## Features

- Customizable tracking
- Simple user interface
- Progress monitoring
- Cloudflare Workers integration

## Technologies

- HTML
- CSS
- JavaScript
- Cloudflare Workers
- Wrangler

## Project Structure

```text
├── worker.js
├── wrangler.json
├── manifest.json
├── app.js
├── style.css
├── index.html
└── README.md
```

## Getting Started

1. Clone the repository.
2. Navigate to the project directory.
3. Start the development server:

   ```bash
   npx wrangler dev
   ```

4. Open the local URL displayed in the terminal.

## Deployment

Deploy the application to Cloudflare Workers:

```bash
npx wrangler deploy
```
